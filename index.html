01 / Problem

Research problem & questions

Predicting mixed martial arts outcomes is difficult because the two athletes' prior experience, physical attributes, striking and grappling histories interact. This research asks whether pre-fight statistics provide useful prediction signals and whether fighter ordering in a dataset can create misleading model performance.

RQ1

How accurately can models predict UFC winners from historical fighter performance?

RQ2

Does fighter-order-balanced training improve prediction performance?

RQ3

Which historical fighter characteristics contribute most to prediction?

Related work & research gap

Logistic Regression and tree ensembles provide established approaches to classification. The methodological focus here is the risk that a fixed fighter position can distort evaluation. Recent UFC-specific literature still needs to be verified and added to the final paper; this page does not claim a comprehensive literature review.

02 / Data

1994–2024

Event date coverage

Five supplied source tables: fight statistics, events, fighter profiles, fighter averages, and fighter medians. The cleaned modeling file contains 43 columns. Features include earlier wins, previous fight count, historical striking and takedown averages, age, height, reach, and weight class.

Data leakage prevention: The target fight's own statistics must not be used to predict its winner. The project uses prior-fight aggregates. Career-wide average and median files are not directly substituted for historical pre-fight values.

Source provenance and redistribution license: original download page/publisher must be verified before public redistribution. Uploaded datasets are provided as course research artifacts pending that verification.

03 / Method

CRISP-DM & experiments

ProblemData understandingPreparationModelingEvaluationResearch reporting

Preprocessing

Join fight and event records, exclude non-binary outcomes, derive prior history, create fighter differences, and impute missing values within training pipelines.

Experiment 1

Majority baseline, Logistic Regression, Random Forest and Gradient Boosting. Select the initial model on validation F1.

Experiment 2

Mirror training matchups, reverse winner labels and fighter-difference features, then compare results on the same chronological test fights.

Evaluation: Accuracy, balanced accuracy, F1, class-specific recall and fighter-order probability symmetry. Chronological train/validation/test separation helps avoid using later fights to train predictions for earlier fights.
